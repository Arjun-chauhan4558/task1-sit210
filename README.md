# Arduino Porch & Hallway Light System

A simple Arduino Nano project that uses a push button to control two LEDs. When the button is pressed, both lights turn on. The porch light turns off after **30 seconds**, followed by the hallway light after another **30 seconds**.

**Components:** Arduino Nano, push button, 2 LEDs, resistors, breadboard and jumper wires.

**Pins:** Button – D4 | Porch Light – D8 | Hallway Light – D9
